สิ่งที่ต้องมีก่อนทำ backend จริง

Authentication ใช้บัญชีผู้ดูแลจริง เช่น GitHub OAuth, Google Workspace หรือระบบ SSO ของหน่วย
Role-Based Access แยกสิทธิ์ผู้เขียนข่าว ผู้ตรวจทาน และผู้เผยแพร่
Audit Log บันทึกว่าใครแก้ข่าวอะไร เมื่อไร และเผยแพร่เวอร์ชันไหน
